# oldforttogether.org

A one-page static archive of the Old Fort Together site: the Don Rimx mural in Old Fort, North Carolina, and the
documentary about it. Served by GitHub Pages at the custom domain in `CNAME`; `404.html` sends old addresses to the
home page. `index.php` is used only by the server that hosted the site before GitHub Pages.

DNS for GitHub Pages: `A` on `oldforttogether.org` → 185.199.108.153, 185.199.109.153, 185.199.110.153,
185.199.111.153; `CNAME` `www` → `tomatillodesign.github.io`.

The photo and icon come from the Internet Archive's copy of the original site.
